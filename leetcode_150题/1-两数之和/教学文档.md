## 问题分析

### 题目要求

- 在数组 `nums` 中找到两个数 `a` 和 `b`，使得 `a + b = target`。
- 返回这两个数的 **下标**。
- 保证有且只有一组解。
- 同一个元素不能使用两次（即下标不能相同）。

### 关键约束

1. **返回的是下标**：如果对数组排序，下标会乱，需要额外处理，所以排序+双指针法比较麻烦。
2. **时间复杂度**：数组长度可达 $10^4$，O(n²) 的暴力法计算量约为 $10^8$，勉强能过，但不是最优解。进阶要求小于 O(n²)。

## 思路解析

### 1. 暴力美学（直觉思路）

最直接的想法是：我先拿第 1 个数，然后把后面所有的数挨个试一遍，看能不能加起来等于 `target`。如果不行，再拿第 2 个数，试它后面的所有数……

- **外层循环**：`i` 从 `0` 到 `n-2`
- **内层循环**：`j` 从 `i+1` 到 `n-1`
- **判断**：`nums[i] + nums[j] == target`

这种方法简单粗暴，绝对正确，但效率较低。

### 2. 空间换时间（哈希表）

我们在暴力法中，对于每一个 `nums[i]`，都在它后面的元素中寻找 `target - nums[i]`。这个“寻找”的过程是一个线性查找 O(n)。

如果我们能用 O(1) 的时间找到 `target - nums[i]` 及其下标，整体效率就能提升到 O(n)。**哈希表（Map）** 正是为此而生。

- Key：数组中的元素值
- Value：该元素对应的下标

我们遍历数组，每遇到一个数 `num`：
1. 先问哈希表：**“你里面有没有一个叫 `target - num` 的数？”**
2. 如果有，那就找到了！直接返回 `[哈希表里的下标, 当前下标]`。
3. 如果没有，就把当前的 `num` 和它的下标存入哈希表，继续看下一个。

---

## 算法详解 (哈希表法)

1. **初始化**：创建一个空的哈希表。
2. **遍历**：从左到右遍历 `nums`，索引为 `i`。
   - 计算需要的另一半：`complement = target - nums[i]`。
   - **查询**：检查 `complement` 是否在哈希表中。
   - **命中**：如果存在，说明之前出现过这个数，取出它的下标 `map[complement]`，结合当前的 `i`，直接返回。
   - **未命中**：如果不存在，将当前数 `nums[i]` 作为 Key，`i` 作为 Value，存入哈希表。

这样，我们只需要遍历一次数组，就能找到答案。

## 代码实现

### C 语言实现（暴力法）
*考虑到 C 语言手写哈希表较繁琐，且初学者应先掌握暴力法。*

```c
int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    // 准备返回结果的数组
    int* result = (int*)malloc(sizeof(int) * 2);
    *returnSize = 2; // 重要：告知调用者返回数组的大小

    // 外层循环：选定第一个数
    for (int i = 0; i < numsSize - 1; i++) {
        // 内层循环：在它后面找第二个数
        for (int j = i + 1; j < numsSize; j++) {
            if (nums[i] + nums[j] == target) {
                result[0] = i;
                result[1] = j;
                return result;
            }
        }
    }
    
    *returnSize = 0;
    return NULL;
}
```

### C++ 实战（哈希表法）
*C++ STL 提供了 `unordered_map`，实现起来非常优雅。*

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // Key: 数值, Value: 下标
        unordered_map<int, int> map;
        
        for (int i = 0; i < nums.size(); ++i) {
            int complement = target - nums[i];
            
            // 查找 map 中是否有需要的另一半
            if (map.find(complement) != map.end()) {
                // 找到了！返回 [之前的下标, 当前下标]
                return {map[complement], i};
            }
            
            // 没找到，把自己记录下来，留给后面的人找
            map[nums[i]] = i;
        }
        
        return {}; // 理论上不会走到这里，因为题目保证有解
    }
};
```

## 复杂度分析

### 1. 暴力法
- **时间复杂度：** O(n²)  
  双重循环，最坏情况下比如 `[1,1,1...2]` 找 `4`，需要比较 $n(n-1)/2$ 次。
- **空间复杂度：** O(1)  
  只需要常数个变量。

### 2. 哈希表法
- **时间复杂度：** O(n)  
  我们只遍历了数组一次，哈希表的查找和插入平均是 O(1)。
- **空间复杂度：** O(n)  
  最坏情况下，我们需要把数组中几乎所有元素都存入哈希表。

## 常见错误

1. **返回局部数组指针（C语言）**  
   ❌ `int ret[2]; return ret;`  
   局部变量在函数结束后会被销毁，返回它的指针是危险的。必须使用 `malloc`。

2. **从 0 开始的内层循环**  
   ❌ `for(j = 0; j < numsSize; j++)`  
   这会导致：
   - 使用同一个元素两次（当 `i == j`）。
   - 重复计算（`[0,1]` 算一次，`[1,0]` 又算一次），虽然正确但效率低。
   ✅ 正确做法：`j = i + 1`，只往后找。

3. **忘记设置 returnSize（C语言）**  
   LeetCode 的 C 语言接口要求修改 `*returnSize` 的值，否则评测器不知道你的数组有多长，会报错或打印乱码。

## 扩展思考

1. **如果数组有序怎么办？**  
   如果是 **有序数组**，我们可以用 **双指针法**（第 167 题）：头尾两个指针，和太大就尾指针左移，和太小就头指针右移。这就能达到 O(n) 时间且 O(1) 空间！
   这也是为什么你可能会想到“双指针”，但本题数组无序，所以不能直接用。

2. **为什么题目说“只有一个有效答案”？**  
   这简化了问题，我们一旦找到一组解就可以立马 `return`，不需要考虑去重或者找所有解。

## 🚀 给 C 语言选手的 C++ 快速上手指南

本题是学习 C++ **STL (标准模板库)** 中 **哈希表** 的绝佳机会。不要被“面向对象”吓倒，我们只把它们当成更高级的“工具”来用。

### 1. 核心概念映射

| C 语言概念 | C++ 对应写法 | 解释 |
|---|---|---|
| `int arr[100]` 或 `int* arr` | `vector<int> arr` | **动态数组**。自带长度记录，会自动管理内存，不用 `malloc` 和 `free`。 |
| `int numsSize` | `nums.size()` | `vector` 自己知道自己有多长。 |
| 手写哈希查找函数 | `map.find(key)` | STL 帮你把哈希函数、冲突处理都做好了，你直接调。 |
| `return NULL` (没找到) | `return map.end()` | C++ 用“指向末尾后面”的迭代器表示“没找到”。 |

### 2. 代码逐行翻译

让我们把 C++ 的解法翻译成“C 语言思路”：

```cpp
unordered_map<int, int> map;
// 翻译：创建一个空的哈希表，键是 int，值也是 int。
// 类似于：HashMap* map = createHashMap();

for (int i = 0; i < nums.size(); ++i) {
// 翻译：标准的 for 循环，只是获取长度的方式变了。

    if (map.find(target - nums[i]) != map.end()) {
    // 翻译：去哈希表里找 (target - nums[i])。
    // 如果返回值不是 map.end()，说明找到了！
    
        return {map[target - nums[i]], i};
        // 翻译：直接把这两个下标打包返回。
        // C++ 允许直接返回 {a, b} 来构造 vector，不用 malloc。
    }
    
    map[nums[i]] = i;
    // 翻译：没找到的话，把当前这个数存进去。
    // Key = nums[i] (数值), Value = i (下标)
    // 类似于：insert(map, nums[i], i);
}
```

### 3. 为什么要学 unordered_map？

在 C 语言中，如果你想用哈希表优化算法（例如从 O(n²) 优化到 O(n)），你需要：
1. 定义一个结构体。
2. 写一个 Hash 函数。
3. 处理哈希冲突（链地址法或开放寻址法）。
4. 写 Insert 函数。
5. 写 Find 函数。
6. **考试时间已经过去一半了...** 😱

而在 C++ 中，只需要一行 `#include <unordered_map>`，你就可以直接使用工业级性能的哈希表。对于算法面试，这是极大的优势！
