# 1. 两数之和

题目来源：https://leetcode.cn/problems/two-sum/description/

---

## 📝 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

---

## ✅ 输出规范

- 函数返回值：`int*` —— 指向包含两个下标的数组的指针。
- 需要设置 `returnSize` 为 2。
- 只有两个数字的下标，顺序不限（例如 `[0, 1]` 或 `[1, 0]` 均可）。

---

## 🔢 示例

### 示例 1

**输入：**  
`nums = [2,7,11,15]`, `target = 9`

**输出：**  
`[0,1]`

**解释：**  
因为 `nums[0] + nums[1] == 9`，返回 `[0, 1]`。

### 示例 2

**输入：**  
`nums = [3,2,4]`, `target = 6`

**输出：**  
`[1,2]`

### 示例 3

**输入：**  
`nums = [3,3]`, `target = 6`

**输出：**  
`[0,1]`

---

## 📌 提示

- `2 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`
- `-109 <= target <= 109`
- **只会存在一个有效答案**

---

## 💡 评测说明

评测机会调用你的函数，并检查返回的两个下标对应的元素之和是否等于 `target`，以及这两个下标是否不同。

```c
int* result = twoSum(nums, numsSize, target, &returnSize);
assert result.length == 2;
assert nums[result[0]] + nums[result[1]] == target;
assert result[0] != result[1];
```
