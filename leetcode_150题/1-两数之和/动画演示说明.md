# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

*(如果之前已经安装过，可跳过此步)*

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序启动后，终端会显示菜单：
- 1: 官方示例 `[2, 7, 11, 15]`, Target `9`
- 2: 示例 `[3, 2, 4]`, Target `6`
- 3: 示例 `[3, 3]`, Target `6`
- 4: 自定义输入（输入你自己的测试数据）

| 按键 | 功能 |

| **空格** / → / Enter | **下一步**（最常用） |

## 📊 动画元素说明

- **蓝色方块 (i)**：当前固定的第一位数。
- **黄色方块 (j)**：当前正在扫描的第二位数。
- **绿色方块**：找到的一对正确答案！
- **Target**：画面左上角的金色方块显示目标值。
- **文字说明**：顶部会实时解释当前正在比较哪两个数，它们的和是多少，以及是否等于 Target。

---

## 💡 观察重点

1. 这里演示的是 **暴力枚举法** (O(n²))。
2. 观察 `i` 是怎么移动的：它从左到右一步步走。
3. 观察 `j` 是怎么移动的：每次 `i` 变了之后，`j` 都重置为 `i + 1`，然后跑到最后。
4. 这就是为什么它慢的原因：比较次数很多。等你在脑海里建立了这个图像，再去学 **哈希表法**，你就会感受到“一次遍历”是多么高效！
