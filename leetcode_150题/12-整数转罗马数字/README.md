## 🎯 核心知识点

- 贪心算法：从最大面值开始向下匹配
- 预建"值-符号"对照表（包含 6 个特殊组合符号）
- 字符串拼接与循环减法
- O(1) 时间复杂度（输入范围固定，循环次数有上界）
