# 12. 整数转罗马数字 — 老师批作业

---

## 📝 初次提交代码

```c
char* intToRoman(int num) {
    int values[]  = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
    char *loma[]  = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"};

    char *result;
    result = (char*)malloc(20*sizeof(char));
    result[0] = '\0';

    int i = 0;
    while (num > 0) {
        while (num >= values[i]) {
            strcat(result, loma[i]);
            num -= values[i];
        }
        i++;
    }
    return result;
}
```

## ✅ 批阅意见

### 总体评价

**非常好！** 思路清晰，代码简洁，是这道题最优雅的贪心写法之一。核心思路完全正确：预建包含 6 个特殊减法片段的"值-符号"对照表，从大到小贪心匹配，一次通过。

---

### 👍 优点

1. **对照表设计完整**  
   13 个片段一个不少，包含了 CM、CD、XC、XL、IX、IV 这 6 个关键的减法组合，省去了所有复杂的 `if` 分支逻辑。

2. **内存初始化规范**  
   `result[0] = '\0'` 写在 `malloc` 之后，确保 `strcat` 从空字符串开始拼接，是良好习惯。

3. **双层 while 结构优雅**  
   外层负责推进 `i`（切换到下一个符号），内层负责连续消耗同一档位的值，逻辑层次分明。

---

### ⚠️ 需要注意的点

1. **`malloc` 大小的估算**  
   `malloc(20)` 能正确覆盖最长罗马数字（例如 3888 → `"MMMDCCCLXXXVIII"`，15 个字符 + `\0`）。但若将来题目范围扩大，需要重新估算。建议在注释中说明：
   ```c
   /* 最长结果约15字符（如MMMDCCCLXXXVIII），20字节足够 */
   ```

2. **调用方需要 `free`**  
   函数返回的堆内存，调用方（如 `main`）必须手动 `free(result)`，否则内存泄漏。在工程代码中要明确在文档或注释中说明所有权。

3. **`strcat` 效率**  
   `strcat` 每次都需要遍历到字符串末尾来定位追加位置，略有冗余。可以维护一个 `len` 变量用 `strcpy(result + len, loma[i]); len += strlen(loma[i]);` 来加速，不过对于本题的 O(1) 规模，实际影响可以忽略不计。
