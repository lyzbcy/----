# 12. 整数转罗马数字

题目来源：https://leetcode.cn/problems/integer-to-roman/

---

## 📝 题目描述

罗马数字包含以下七种字符：`I`，`V`，`X`，`L`，`C`，`D`，`M`。

| 字符 | 数值 |
|------|------|
| I    | 1    |
| V    | 5    |
| X    | 10   |
| L    | 50   |
| C    | 100  |
| D    | 500  |
| M    | 1000 |

例如，罗马数字 2 写做 `II`，即为两个并列的 1。12 写做 `XII`，即为 `X + II`。27 写做 `XXVII`，即为 `XX + V + II`。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V`（5）和 `X`（10）的左边，来表示 4 和 9。
- `X` 可以放在 `L`（50）和 `C`（100）的左边，来表示 40 和 90。
- `C` 可以放在 `D`（500）和 `M`（1000）的左边，来表示 400 和 900。

给你一个整数，将其转为罗马数字。

---

## ✅ 输入输出

**输入：** 一个整数 `num`，范围 `[1, 3999]`

**输出：** 一个字符串，表示对应的罗马数字

---

## 🔢 示例

### 示例 1

**输入：**  
`num = 3749`

**输出：**  
`"MMMDCCXLIX"`

**解释：**  
`3000 = MMM`，`700 = DCC`，`40 = XL`，`9 = IX`，合并得 `MMMDCCXLIX`。

---

### 示例 2

**输入：**  
`num = 58`

**输出：**  
`"LVIII"`

**解释：**  
`50 = L`，`5 = V`，`3 = III`，合并得 `LVIII`。

---

### 示例 3

**输入：**  
`num = 1994`

**输出：**  
`"MCMXCIV"`

**解释：**  
`1000 = M`，`900 = CM`，`90 = XC`，`4 = IV`，合并得 `MCMXCIV`。

---

## 📌 提示

- `1 <= num <= 3999`
- 输入保证为有效整数，输出保证为合法罗马数字字符串

---

## 💡 伪代码

```
// 预建"值-符号"对照表（从大到小，含6个特殊组合）
values[]  = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1}
symbols[] = {"M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"}

函数 intToRoman(num):
    result = ""
    对 i 从 0 到 12:
        当 num >= values[i]:
            result += symbols[i]
            num -= values[i]
    返回 result
```

---

**目标：** 用 O(1) 时间（输入范围固定）实现整数到罗马数字的转换，正确处理 6 个特殊组合。
