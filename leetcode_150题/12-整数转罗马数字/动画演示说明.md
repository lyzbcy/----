## 🎨 动画元素解释

| 元素            | 含义                                       |
|-----------------|--------------------------------------------|
| 左侧对照表      | 13 个原子片段（值 + 符号），金色高亮当前档 |
| 剩余 num        | 当前还未"兑换"的整数值                     |
| 当前结果        | 已拼接的罗马数字字符串（蓝色加粗）         |
| 右侧代码面板    | C 代码同步高亮，橙色表示当前执行行         |
| 顶部动作说明    | 本步操作的简洁描述                         |
| 绿色解释框      | 当前步骤的详细说明                         |

## 🔄 流程说明

1. **初始化**：num 赋为原始值，结果字符串为空，i=0（从 M=1000 开始）。
2. **外层 while**：只要 num > 0 就继续。
3. **内层 while**：当 num ≥ values[i] 时，反复拼接 symbols[i] 并减去 values[i]。
4. **推进 i**：内层退出后，i++，切换到下一个更小的档位。
5. **结束**：num 归零，返回结果字符串。

贪心的妙处：**6 个特殊减法组合（IV、IX、XL、XC、CD、CM）直接放进表里，不需要任何 `if` 分支！**

---

## 📚 学习建议

1. 先用 `num=4` 或 `num=9` 这样的小数字走一遍，看清 `IV` / `IX` 是如何从表中直接匹配的。
2. 再用 `num=1994` 走一遍，观察 CM（900）、XC（90）、IV（4）三个特殊组合如何依次被消耗。
3. 对比当 num 不满足某档时的"跳过"步骤，感受外层 while 推进 i 的逻辑。

## ❓ 常见问题

**Q：窗口弹出后按键没反应？**  
A：需要先用鼠标点击一下弹出的 matplotlib 窗口，使其获取焦点后再按键。

**Q：中文显示方框乱码？**  
A：脚本顶部已配置 SimHei / Microsoft YaHei 字体，Windows 环境通常正常。若出现问题，可将 `plt.rcParams['font.sans-serif']` 改为系统中已安装的中文字体名称。

**Q：可以修改输入范围超过 3999 吗？**  
A：对照表仅覆盖 `[1, 3999]`，超出后 `i` 会越界。若需扩展，需在表中追加更大的符号。
