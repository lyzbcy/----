# 36. 有效的数独

题目来源：https://leetcode.cn/problems/valid-sudoku/

---

## 📝 题目描述

请你判断一个 `9 × 9` 的数独是否有效。只需要根据以下规则，验证**已经填入**的数字是否有效即可。

1. 数字 `1-9` 在每一**行**只能出现一次。
2. 数字 `1-9` 在每一**列**只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3×3` **宫**内只能出现一次。

**注意：**

- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

---

## ✅ 输入输出

**输入：** 一个 `9×9` 的字符型二维数组 `board`，元素为 `'1'~'9'` 或 `'.'`

**输出：** `true` 表示当前已填入数字满足数独规则；`false` 表示存在冲突

---

## 🔢 示例

### 示例 1

**输入：**
```
board =
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".",".","8",".",".","7","9"]
,[".",".",".",".","8",".",".","7","9"]]
```

**输出：** `true`

---

### 示例 2

**输入：** 与示例 1 相同，但第一行第一个数字从 `5` 改为 `8`（左上角 3×3 宫中出现两个 8）

**输出：** `false`

**解释：** 左上角 3×3 宫内有两个 `8`，违反规则。

---

## 📌 提示

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字（`'1'`~`'9'`）或者 `'.'`

---

## 💡 伪代码

```
初始化：
    row[9][10] = all false   // row[i][num]: 第i行数字num是否已出现
    col[9][10] = all false   // col[j][num]: 第j列数字num是否已出现
    box[9][10] = all false   // box[b][num]: 第b宫数字num是否已出现

对 i 从 0 到 8:
    对 j 从 0 到 8:
        若 board[i][j] == '.': 跳过
        
        num = board[i][j] - '0'          // 字符转数字
        boxIndex = (i/3)*3 + (j/3)       // 计算宫编号(0~8)
        
        若 row[i][num] 或 col[j][num] 或 box[boxIndex][num]:
            返回 false                    // 发现重复
        
        标记 row[i][num] = true
        标记 col[j][num] = true
        标记 box[boxIndex][num] = true

返回 true
```

---

**目标：** 用 O(81) = O(1) 时间（固定大小棋盘）、O(243) = O(1) 空间完成一次遍历验证。
