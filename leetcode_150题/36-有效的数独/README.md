## 🎯 核心知识点

- 哈希表（布尔数组）记录已出现数字
- 宫（3×3 格）编号公式：`boxIndex = (i/3)*3 + j/3`
- 一次遍历同时检查行、列、宫，O(1) 空间
- 字符转数字：`num = board[i][j] - '0'`
