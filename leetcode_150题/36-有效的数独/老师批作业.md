# 36. 有效的数独 — 老师批作业

---

## 📝 初次提交代码

```c
bool isValidSudoku(char** board, int boardSize, int* boardColSize) {
    bool row[9][10] = {false};   // row[i][1~9]
    bool col[9][10] = {false};
    bool box[9][10] = {false};

    for(int i=0;i<9;i++){
        for(int j=0;j<9;j++){
            if(board[i][j]=='.'){
                continue;
            }
            int num=board[i][j]-'0';
            int boxindex=(i/3)*3+j/3;

            if (row[i][num] || col[j][num] || box[boxindex][num]) {
                return false;
            }
            row[i][num] = true;
            col[j][num] = true;
            box[boxindex][num] = true;
        }
    }
    return true;
}
```

---

## ✅ 批阅意见

### 总体评价

**相当优秀！** 思路一步到位，三表同步、一次遍历，直接命中本题最优解法。宫编号公式 `(i/3)*3+j/3` 写得非常正确，字符转数字也到位。

---

### 👍 优点

1. **三表一次遍历，思路最优**  
   没有分三轮扫描（按行查 → 按列查 → 按宫查），而是直接在同一个双重循环里同时更新并检查 row / col / box，效率最高，代码最简洁。

2. **宫编号公式正确**  
   `boxindex = (i/3)*3 + j/3` 是本题最关键的公式，写对了就等于做出来一大半，你对整数除法（地板除）的理解很到位。

3. **字符转数字处理正确**  
   `num = board[i][j] - '0'` 简洁安全，配合 `[10]` 大小的数组让下标 1~9 自然对应，没有越界风险。

4. **跳过空格逻辑清晰**  
   在转换之前先 `continue`，避免了对 `'.'` 的错误计算。

---

### ⚠️ 需要注意的点

1. **C 语言局部数组的初始化**  
   代码里用了 `= {false}` 初始化，这只能将**第一个元素**置为 false，剩余元素依靠 C 标准的"部分初始化补零"规则才全部为 0。在大多数平台上没问题，但更保险的写法是用 `memset`：
   ```c
   bool row[9][10], col[9][10], box[9][10];
   memset(row, 0, sizeof(row));
   memset(col, 0, sizeof(col));
   memset(box, 0, sizeof(box));
   ```
   或者声明为全局/静态变量（会自动清零）。

2. **命名规范小建议**  
   `boxindex` 可以写成 `boxIndex`（驼峰）或 `box_index`（下划线），与 `row`、`col` 的风格保持一致，可读性更好。这是代码风格问题，不影响正确性。

3. **`boardSize` 和 `boardColSize` 参数未使用**  
   题目固定是 9×9，所以直接硬编码 `9` 没有问题。若是通用版本应使用这两个参数，但本题无需担心。

### 💡 进阶：位运算压缩

若追求更小内存占用，可将三张 `bool[9][10]` 换成 `int[9]`，用位运算代替布尔数组：

```c
int row[9] = {0}, col[9] = {0}, box[9] = {0};
// 检查
if ((row[i] >> num) & 1) return false;
// 标记
row[i] |= (1 << num);
```

内存从 270 字节降到 108 字节，但可读性略下降。本题不要求，了解即可。
