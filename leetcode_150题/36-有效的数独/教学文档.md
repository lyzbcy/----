# 36. 有效的数独 — 教学文档

---

## 一、问题分析

给定一个 9×9 的棋盘，每格是 `'1'~'9'` 或 `'.'`（空白）。要验证**已填入**的数字是否满足三条数独规则：

- 每行数字 1~9 各最多出现一次
- 每列数字 1~9 各最多出现一次
- 每个 3×3 宫内数字 1~9 各最多出现一次

**不需要判断数独是否有唯一解，只验证有无冲突！**

---

## 二、思路解析

### ❌ 错误直觉：三次扫描

很多人的第一反应是：先扫一遍检查行，再扫一遍检查列，再扫一遍检查宫。

这样做虽然正确，但**三次扫描 × 81 次 = 243 次遍历**，而且代码冗长，还需要三个独立的辅助检查函数。

### ✅ 正确思路：三表预分配 + 一次遍历

核心观察：**行、列、宫的检查可以同时进行！**

预先分配三张 `bool[9][10]` 表：

| 表名 | 含义 |
|------|------|
| `row[i][num]` | 第 `i` 行数字 `num` 是否已出现 |
| `col[j][num]` | 第 `j` 列数字 `num` 是否已出现 |
| `box[b][num]` | 第 `b` 宫数字 `num` 是否已出现 |

遍历每个格子时，同时查询并更新三张表。**一次遍历搞定一切！**

## 三、关键技巧：宫编号公式

9 个 3×3 宫如何编号？

```
宫 0 | 宫 1 | 宫 2
─────┼──────┼─────
宫 3 | 宫 4 | 宫 5
─────┼──────┼─────
宫 6 | 宫 7 | 宫 8
```

对于格子 `(i, j)`，所属宫的编号为：

```
boxIndex = (i / 3) * 3 + j / 3
```

- `i/3` 确定宫的行号（0、1、2）
- `j/3` 确定宫的列号（0、1、2）
- `(i/3)*3 + j/3` 将二维宫坐标映射到 0~8

**举例：**
- 格子 `(0,0)` → `(0/3)*3 + 0/3 = 0` → 宫 0
- 格子 `(4,7)` → `(4/3)*3 + 7/3 = 3+2 = 5` → 宫 5
- 格子 `(8,8)` → `(8/3)*3 + 8/3 = 6+2 = 8` → 宫 8

## 四、算法详解

```
初始化三张全 false 的布尔表

for i in 0..8:
    for j in 0..8:
        若 board[i][j] == '.': 跳过
        
        num      = board[i][j] - '0'      // 字符 → 整数
        boxIndex = (i/3)*3 + j/3          // 宫编号
        
        若 row[i][num] 或 col[j][num] 或 box[boxIndex][num]:
            return false                   // 发现重复
        
        row[i][num] = col[j][num] = box[boxIndex][num] = true

return true
```

## 五、代码实现（C 关键片段）

```c
bool row[9][10], col[9][10], box[9][10];
memset(row, false, sizeof(row));
memset(col, false, sizeof(col));
memset(box, false, sizeof(box));

for (int i = 0; i < 9; i++) {
    for (int j = 0; j < 9; j++) {
        if (board[i][j] == '.') continue;
        int num      = board[i][j] - '0';
        int boxIndex = (i / 3) * 3 + j / 3;
        if (row[i][num] || col[j][num] || box[boxIndex][num])
            return false;
        row[i][num] = col[j][num] = box[boxIndex][num] = true;
    }
}
```

> ⚠️ **为什么下标用 `[10]` 而不是 `[9]`？**  
> 数字范围是 1~9，使用 `num` 作为下标时最大为 9。若数组只有 `[9]`（下标 0~8），访问 `[9]` 会越界。用 `[10]` 让下标 0 作为占位，1~9 自然对应。

## 七、常见错误

| 错误类型 | 描述 | 解决方案 |
|---------|------|---------|
| 宫编号算错 | 用 `i*9+j` 或其他错误公式 | 记住 `(i/3)*3 + j/3` |
| 数组越界 | `bool arr[9][9]`，但 `num` 最大为 9 | 改为 `bool arr[9][10]` |
| 忘记跳过 `.` | 对 `'.'` 计算 `num = '.' - '0'`（负数/乱值）| 先 `if board[i][j]=='.' continue` |
| 未初始化 | C 语言局部数组不自动置零 | 用 `memset` 或 `= {false}` 初始化 |

## 八、扩展思考

1. **如果要解数独（37题）怎么做？**  
   在本题的验证基础上加回溯：对每个 `'.'` 尝试填 1~9，填一个验证一次，不合法就回退。

2. **可以用位运算压缩吗？**  
   可以！用 `int row[9]`，第 `num` 位表示该数字是否已出现：`row[i] & (1 << num)` 替代布尔表，内存减少 10 倍。

3. **时间复杂度真的是 O(1) 吗？**  
   是的，因为输入规模固定为 81 格，无论"n"如何变化（本题没有 n），都是常数时间。
