# 36. 有效的数独 — 动画演示说明

---

## 📦 依赖安装

```bash
pip install matplotlib numpy
```

---

## ▶️ 运行方式

```bash
python 动画演示.py
```

运行后在终端选择示例（有效棋盘 / 有冲突棋盘），回车后弹出动画窗口。

| 2    | 左上宫有两个 8（示例2）| `false`，动画会在冲突格停下并标红 |

## 🎨 动画元素解释

| 元素 | 含义 |
|------|------|
| 棋盘左侧 | 9×9 数独格，粗线划分 3×3 宫 |
| **绿色**格 | 已扫描完毕的格子 |
| **黄色**格 | 当前正在处理的格子 |
| **红色**格 | 发现冲突的格子 |
| row 标记表 | 9行×9列小方格，金色表示该数字已在对应行出现 |
| col 标记表 | 同上，按列统计 |
| box 标记表 | 同上，按宫编号统计 |
| 右侧代码面板 | C 代码同步高亮，橙色为当前执行行 |

---

## 🔄 流程说明

1. **初始化**：三张 `bool[9][10]` 表全部置 false。
2. **逐格扫描**：遇到 `'.'` 跳过；否则计算 `num` 和 `boxIndex`。
3. **检查冲突**：同时查询 `row[i][num]`、`col[j][num]`、`box[boxIndex][num]`。
4. **发现冲突**：格子变红，动画停在该步，显示 ❌ false。
5. **无冲突**：三表同时标记，继续扫描，最终显示 ✅ true。

---

## 📚 学习建议

1. 先选示例 1（有效棋盘），观察三张表如何逐步被填满但始终不冲突。
2. 再选示例 2（冲突棋盘），找到第一个"金色格已有这个数字"的时刻，感受检测逻辑。
3. 重点观察宫标记表（box）：`(i/3)*3+j/3` 如何将 9 个宫统一编号为 0~8。

---

## ❓ 常见问题

**Q：三张小表太小看不清？**  
A：可以在代码里调大 `cell = 0.35` 参数，或放大窗口后用 matplotlib 的缩放工具。

**Q：中文乱码？**  
A：确认系统已安装 SimHei 或 Microsoft YaHei 字体，或在顶部 `rcParams` 换成本机已有中文字体。
