## 批阅意见

### 常见错误提醒

在批阅学生代码时，请重点关注以下常见问题：

#### 1. k 的索引问题 🔴

```c
// ❌ 错误：忘记转换索引
quickSelect(arr, 0, n-1, k);  // k 是 1-indexed

// ✅ 正确：转为 0-indexed
quickSelect(arr, 0, n-1, k-1);
```

#### 2. 分区边界错误

```c
// ❌ 错误：j 包含了 right（pivot）
for (int j = left; j <= right; j++)

// ✅ 正确：j 只到 right-1
for (int j = left; j < right; j++)
```

#### 3. 递归终止条件遗漏

```c
// ✅ 必须添加
if (left == right) {
    return arr[left];
}
```

#### 4. 相等元素处理

```c
// ❌ 可能出问题
if (arr[j] < pivot)

// ✅ 使用 <= 处理重复元素
if (arr[j] <= pivot)
```

#### 5. 直接用排序（效率低）

```c
// ❌ 虽然正确，但效率不是最优
qsort(arr, n, sizeof(int), cmp);
return arr[k-1];

// ✅ 使用快速选择，期望 O(n)
```

## 📝 参考答案要点

1. **分区操作**：选择 pivot，将数组分成 ≤pivot 和 >pivot
2. **递归选择**：只在需要的那一半继续递归
3. **终止条件**：left == right 时返回
4. **时间复杂度**：O(n) 期望
5. **空间复杂度**：O(log n) 递归栈
