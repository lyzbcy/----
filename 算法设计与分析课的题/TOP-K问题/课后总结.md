## 思路关键点

1. **分治思想**：
   - 选择 pivot 分区
   - 只处理包含 k 的那一半
   - 不需要完全排序

2. **分区操作**：
   ```
   把 ≤ pivot 的放左边
   把 > pivot 的放右边
   返回 pivot 的最终位置
   ```

3. **递归决策**：
   - k < pivot位置 → 左边找
   - k > pivot位置 → 右边找
   - k == pivot位置 → 找到了！

4. **时间复杂度**：
   - 期望 O(n)
   - 最坏 O(n²)，使用随机化避免
