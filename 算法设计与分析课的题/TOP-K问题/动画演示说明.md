# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序提供三个内置选项：

- 选项 1：题目样例 [1, 3, 2, 5, 4], k=4
- 选项 2：8个随机数
- 选项 3：自定义输入

---

## 🎮 手动控制方式

| 按键 | 功能 |
|------|------|
| 空格 / → / Enter | 下一步 |
| ← | 上一步 |
| Home | 跳转到第一步 |
| End | 跳转到最后一步 |
| Q / Esc | 退出程序 |

> ⚠️ 使用键盘前，请先点击动画窗口以确保焦点在窗口上。

---

## 📊 动画元素说明

- **蓝色柱子**：当前搜索范围内的元素
- **红色柱子**：选中的 Pivot（基准元素）
- **橙色柱子**：正在交换的元素
- **绿色柱子**：找到的答案（第 k 小的数）
- **灰色柱子**：已排除的元素

---

## 🔁 动画流程

1. **选择 Pivot**：选择最右边的元素作为基准
2. **分区过程**：将 ≤ pivot 的元素移到左边
3. **分区完成**：pivot 到达最终位置
4. **递归决策**：根据 k 的位置决定在哪一边继续
5. **找到答案**：当 k 正好是 pivot 位置时结束

---

## 💡 学习建议

1. **第一次观看**：选择示例 1，观察基本的分区流程
   - 注意 pivot 是如何选择的
   - 观察元素如何被交换到正确的一边

2. **第二次**：尝试随机数组
   - 观察不同 pivot 选择对分区结果的影响
   - 理解为什么只需要处理一半

3. **第三次**：自定义输入
   - 预测下一步的操作
   - 验证你的分析

---

## 🎯 关键观察点

1. **分区不变量**：
   - 左边所有元素 ≤ pivot
   - 右边所有元素 > pivot

2. **递归方向**：
   - k < pivot位置 → 在左边找
   - k > pivot位置 → 在右边找
   - k == pivot位置 → 找到了！

3. **效率提升**：
   - 每次只处理一半
   - 期望时间复杂度 O(n)

---

## ❓ 常见问题

- **柱子太矮看不清？**  
  数值差异太大时可能出现，可以尝试使用更均匀的数据。

- **中文显示异常？**  
  修改脚本中的 `plt.rcParams['font.sans-serif']`。

- **动画步数太多？**  
  快速选择在最坏情况下步数较多，但通常很快就能找到答案。
