# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序提供三个内置选项：

- 选项 1：题目样例（3个物品）
- 选项 2：5个物品示例
- 选项 3：自定义输入

---

## 📊 动画元素说明

- **DP 表格**：显示 dp[重量][体积] 的值
- **红色高亮**：当前正在更新的单元格
- **箭头标记**：当前正在处理的物品
- **状态信息**：显示当前操作的详细说明

---

## 🔁 动画流程

1. **初始化**：创建全零的 DP 表格
2. **遍历物品**：依次处理每个物品
3. **状态转移**：更新满足条件的 dp 值
4. **结束**：显示最终的最大价值

---

## 💡 学习建议

1. **第一次观看**：选择示例 1，观察基本的填表流程
   - 注意逆序遍历的顺序
   - 观察哪些单元格被更新

2. **第二次**：尝试示例 2，理解更多物品的情况
   - 观察物品选择的决策过程
   - 注意最优解的构建

3. **第三次**：自定义输入，验证你的理解
   - 预测下一步的更新
   - 检验自己的分析是否正确

---

## 🎯 关键观察点

1. **逆序遍历**：为什么从大到小遍历？
   - 保证每个物品只被选一次
   - 避免使用已更新的值

2. **状态转移**：`dp[j][k] = max(dp[j][k], dp[j-w][k-c] + v)`
   - 不选当前物品：保持原值
   - 选当前物品：从更小容量转移

3. **最终答案**：`dp[W][V]` 即为所求

---

## ❓ 常见问题

- **表格显示不完整？**  
  当 W 或 V 较大时，只显示部分表格以保证可读性。

- **中文显示异常？**  
  修改脚本中的 `plt.rcParams['font.sans-serif']`，换成系统可用字体。

- **数值看不清？**  
  尝试最大化窗口或调整 figsize 参数。
