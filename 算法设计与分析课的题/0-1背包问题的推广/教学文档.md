## 问题分析

### 题目要求

- 有 n 种物品，第 i 种物品有价值 v[i]、重量 w[i]、体积 c[i]
- 背包有重量限制 W 和体积限制 V
- 每种物品最多选一次（0-1 约束）
- 目标：在双重约束下，使总价值最大

### 与经典背包的区别

| 问题类型 | 约束条件 | 状态维度 |
|----------|----------|----------|
| 经典0-1背包 | 仅重量限制 | 二维 dp[i][w] |
| **本题** | 重量 + 体积 | 三维 dp[i][w][v] |

### 关键约束

1. **双重限制**：同时满足重量 ≤ W 和体积 ≤ V
2. **0-1 约束**：每种物品只能取或不取，不可分割
3. **数据规模**：n ≤ 100, W ≤ 110, V ≤ 110

## 思路解析

### 错误直觉 ❌

- **贪心算法**：按价值/重量比或价值/体积比排序，依次选取
  - 错误原因：无法保证最优解，反例很多
  
- **只考虑一个约束**：忽略体积或重量限制
  - 错误原因：两个约束必须同时满足

### 正确思路 ✅

本题是经典 **动态规划** 问题，需要设计三维状态：

1. **状态定义**：`dp[i][j][k]` 表示考虑前 i 个物品，重量不超过 j，体积不超过 k 时的最大价值

2. **状态转移**：
   - 不选第 i 个物品：`dp[i][j][k] = dp[i-1][j][k]`
   - 选第 i 个物品（如果能装下）：`dp[i][j][k] = dp[i-1][j-w[i]][k-c[i]] + v[i]`
   - 取两者最大值

3. **边界条件**：`dp[0][j][k] = 0`（没有物品时价值为 0）

4. **最终答案**：`dp[n][W][V]`

---

## 算法详解

### 1. 状态转移方程

```
dp[i][j][k] = max(dp[i-1][j][k], dp[i-1][j-w[i]][k-c[i]] + v[i])

其中：
- 第一项：不选第 i 个物品
- 第二项：选第 i 个物品（前提是 j >= w[i] 且 k >= c[i]）
```

### 2. 填表顺序

```
for i = 1 to n:           // 遍历每个物品
    for j = W down to w[i]:   // 遍历重量（逆序！）
        for k = V down to c[i]:   // 遍历体积（逆序！）
            dp[j][k] = max(dp[j][k], dp[j-w[i]][k-c[i]] + v[i])
```

### 3. 空间优化

原始三维数组 `dp[n][W][V]` 可以优化为二维 `dp[W][V]`：

**关键技巧**：**逆序遍历**重量和体积，保证使用的是上一行的值

```c
// 空间优化后的代码
for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {      // 必须逆序！
        for (int k = V; k >= c[i]; k--) {  // 必须逆序！
            dp[j][k] = max(dp[j][k], dp[j-w[i]][k-c[i]] + v[i]);
        }
    }
}
```

### 4. 为什么必须逆序遍历？

如果正序遍历，会导致同一物品被重复选择：

```
假设 w[0] = 2, c[0] = 3, v[0] = 5
正序遍历时：
dp[2][3] = dp[0][0] + 5 = 5  ✗ 使用了物品0
dp[4][6] = dp[2][3] + 5 = 10 ✗ 又使用了物品0！（重复）

逆序遍历时：
dp[4][6] = dp[2][3] + 5  // 此时 dp[2][3] 还是旧值
dp[2][3] = dp[0][0] + 5  // 才更新 dp[2][3]
```

## 代码实现

### C 语言核心代码

```c
int maxValue(int n, int W, int V, int w[], int c[], int v[]) {
    // dp[j][k] 表示重量不超过j，体积不超过k时的最大价值
    int dp[W + 1][V + 1];
    memset(dp, 0, sizeof(dp));
    
    for (int i = 0; i < n; i++) {
        // 逆序遍历，避免同一物品被多次选择
        for (int j = W; j >= w[i]; j--) {
            for (int k = V; k >= c[i]; k--) {
                if (dp[j - w[i]][k - c[i]] + v[i] > dp[j][k]) {
                    dp[j][k] = dp[j - w[i]][k - c[i]] + v[i];
                }
            }
        }
    }
    
    return dp[W][V];
}
```

### 状态转移的直观理解

想象你正在装箱：

1. 遍历每个物品
2. 对于每个物品，问自己："如果我选这个物品，能获得更高的价值吗？"
3. 比较"选"与"不选"的价值，取更大的

## 复杂度分析

### 时间复杂度

- **外层循环**：遍历 n 个物品，O(n)
- **重量循环**：最多 O(W) 次
- **体积循环**：最多 O(V) 次
- **总体**：O(n × W × V)

对于本题：n ≤ 100, W ≤ 110, V ≤ 110
总运算次数约 100 × 110 × 110 ≈ 1.21 × 10⁶，完全可行。

### 空间复杂度

- **优化前**：O(n × W × V) 三维数组
- **优化后**：O(W × V) 二维数组，本题约 110 × 110 × 4B ≈ 48KB

## 常见错误

1. **正序遍历导致物品重复选择**
   ```c
   // ❌ 错误：正序遍历
   for (int j = w[i]; j <= W; j++)
   
   // ✅ 正确：逆序遍历
   for (int j = W; j >= w[i]; j--)
   ```

2. **忘记初始化 dp 数组**
   ```c
   // ✅ 正确：初始化为 0
   memset(dp, 0, sizeof(dp));
   ```

3. **边界条件错误**
   ```c
   // ❌ 错误：数组越界
   for (int j = W; j >= 0; j--)  // j-w[i] 可能为负
   
   // ✅ 正确：保证不越界
   for (int j = W; j >= w[i]; j--)  // j-w[i] >= 0
   ```

4. **输入顺序搞混**
   题目要求输入顺序是：重量 w[i]、体积 c[i]、价值 v[i]
   注意不要搞混顺序！

5. **数据类型溢出**
   如果 n, W, V 很大，dp 数组可能需要 long long

## 扩展思考

1. **输出选择的物品**
   如何追踪哪些物品被选中了？
   - 方法一：回溯法，从 dp[W][V] 反向追踪
   - 方法二：额外记录选择路径

2. **完全背包扩展**
   如果每种物品可以无限选择，如何修改算法？
   - 答案：将逆序遍历改为正序遍历

3. **更多约束维度**
   如果有三个约束（重量、体积、数量），如何扩展？
   - 答案：使用三维 dp 数组，类似方法推广

4. **背包恰好装满**
   如果要求恰好用完所有容量，如何修改？
   - 答案：初始化 dp[0][0] = 0，其他设为 -∞

5. **方案数统计**
   如何统计最优解的方案数？
   - 答案：再开一个 count 数组记录达到最大价值的方案数
