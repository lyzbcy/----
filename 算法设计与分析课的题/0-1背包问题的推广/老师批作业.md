## 批阅意见

### 常见错误提醒

在批阅学生代码时，请重点关注以下常见问题：

#### 1. 遍历顺序错误 🔴

```c
// ❌ 错误写法 - 正序遍历会导致物品重复选择
for (int j = w[i]; j <= W; j++) {
    for (int k = c[i]; k <= V; k++) {

// ✅ 正确写法 - 必须逆序遍历
for (int j = W; j >= w[i]; j--) {
    for (int k = V; k >= c[i]; k--) {
```

#### 2. 输入顺序搞混

```c
// 题目要求的输入顺序：重量、体积、价值
scanf("%d %d %d", &w[i], &c[i], &v[i]);

// 不要搞混为：价值、重量、体积
```

#### 3. 数组越界

```c
// ❌ 错误：可能导致负数下标
for (int j = W; j >= 0; j--) {
    dp[j-w[i]][k-c[i]]  // j-w[i] 可能为负

// ✅ 正确：保证下标非负
for (int j = W; j >= w[i]; j--) {
    // j-w[i] >= 0 保证合法
```

#### 4. 状态转移方程写错

```c
// ❌ 错误：加法写成了赋值
dp[j][k] = dp[j - w[i]][k - c[i]] + v[i];

// ✅ 正确：需要取最大值
dp[j][k] = max(dp[j][k], dp[j - w[i]][k - c[i]] + v[i]);
```

#### 5. 忘记初始化

```c
// ✅ 必须初始化 dp 数组为 0
memset(dp, 0, sizeof(dp));
```

## 📝 参考答案要点

1. **状态定义**：`dp[j][k]` 表示重量不超过 j、体积不超过 k 时的最大价值
2. **状态转移**：`dp[j][k] = max(dp[j][k], dp[j-w[i]][k-c[i]] + v[i])`
3. **遍历顺序**：物品正序，重量和体积逆序
4. **时间复杂度**：O(n × W × V)
5. **空间复杂度**：O(W × V)
