## 📖 学习路径

1. **阅读题目要求**  
   打开 `题目描述.md`，理解题目背景、输入输出与约束。

2. **观看动画演示（强烈推荐）🎬**  
   运行 `python 动画演示.py`，直观观察动态规划表的填充过程。  
   详细操作说明见 `动画演示说明.md`。

3. **深入理解思路**  
   打开 `教学文档.md`，逐步掌握：
   - 问题分析
   - 状态定义与转移方程
   - 动态规划算法详解
   - 空间优化技巧
   - 常见陷阱与边界处理

4. **查看代码实现**  
   根据需要查阅 `答案.c` 或 `答案.cpp`。

5. **复盘总结**  
   在完成题目后，填写 `课后总结.md` 模板，巩固所学。

## 🎯 核心知识点

- 动态规划（Dynamic Programming）的应用
- 多维约束条件的状态设计
- 0-1背包问题的扩展变形
- 三维 DP 状态压缩到二维
- 逆序遍历避免状态覆盖
- 时间复杂度分析：O(n × W × V)

## 🎬 快速开始动画演示

```bash
# 安装依赖
pip install matplotlib numpy

# 运行动画
python 动画演示.py
```

动画支持手动逐步播放，方便你按照自己的节奏理解动态规划的状态转移过程。
