## 思路关键点

1. **状态定义**：`dp[j][k]` 表示重量不超过 j、体积不超过 k 时的最大价值

2. **逆序遍历**：
   - 0-1 背包必须逆序遍历容量
   - 保证每个物品只被选一次
   - 避免覆盖还要用到的旧值

3. **状态转移**：
   ```
   dp[j][k] = max(不选, 选)
            = max(dp[j][k], dp[j-w][k-c] + v)
   ```

4. **空间优化**：从三维压缩到二维
