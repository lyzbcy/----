# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序提供三个内置选项：

- 选项 1：2×3 网格（题目样例）
- 选项 2：3×3 网格
- 选项 3：自定义输入

---

## 🎮 手动控制方式

| 按键 | 功能 |
|------|------|
| 空格 / → / Enter | 下一步 |
| ← | 上一步 |
| Home | 跳转到第一步 |
| End | 跳转到最后一步 |
| Q / Esc | 退出程序 |

> ⚠️ 使用键盘前，请先点击动画窗口以确保焦点在窗口上。

---

## 📊 动画元素说明

- 👮 **哨兵图标**：表示该格子放置了哨兵
- 🟥 **红色格子**：哨兵所在位置
- 🟩 **绿色格子**：被哨兵覆盖的格子（数字表示被覆盖次数）
- ⬜ **白色格子**：未被覆盖
- 🔵 **蓝色边框**：当前正在处理的格子

---

## 🔁 动画流程

1. **遍历每个格子**：从左到右、从上到下
2. **可行性剪枝**：如果上方格子未覆盖，强制放置
3. **分支决策**：不放/放哨兵
4. **回溯**：撤销放置，尝试其他分支
5. **找到解**：记录并继续搜索

---

## 💡 学习建议

1. **第一次观看**：选择 2×3 网格，观察完整流程
   - 注意强制放置的触发条件
   - 观察覆盖计数的变化

2. **第二次**：选择 3×3 网格
   - 观察更多的剪枝情况
   - 理解为什么先尝试"不放"

3. **思考问题**：
   - 什么时候会触发"强制放置"？
   - 回溯时发生了什么？

---

## 🎯 关键观察点

1. **覆盖计数**：
   - 每个格子显示被覆盖的次数
   - 放置哨兵时，周围5格 +1
   - 回溯时，周围5格 -1

2. **强制放置**：
   - 当 (r-1, c) 覆盖数为 0
   - 必须在 (r, c) 放置哨兵
   - 这是"最后机会"原则

3. **先不放后放**：
   - 优先尝试不放置
   - 可以更快找到较小的解
   - 有利于剪枝

---

## ❓ 常见问题

- **步骤太多？**  
  网格越大步骤越多，可以选择小网格先理解原理。

- **中文显示异常？**  
  修改脚本中的 `plt.rcParams['font.sans-serif']`。

- **网页版动画？**  
  可以直接打开 `index.html` 查看交互式网页版本。
