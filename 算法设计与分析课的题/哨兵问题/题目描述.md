# 哨兵问题

题目来源：算法设计与分析课程作业

---

## 📝 题目描述

在一个 m × n 的陈列室中，需要布置哨兵。每个哨兵可以监视**自己所在的方格**以及**上下左右四个相邻的方格**（共5个格子）。

**目标**：求监视整个陈列室所需的**最小哨兵数量**，以及达到该最小数量的**方案数**。

---

## 📥 输入形式

一行两个整数 m 和 n，表示陈列室的行数和列数。

---

## 📤 输出形式

- 第一行：最小哨兵数量
- 第二行：达到最小哨兵数量的方案数

---

## 🔢 示例

### 示例 1

**输入：**
```
2 3
```

**输出：**
```
2
3
```

**解释：**
在 2×3 的网格中，最少需要 2 个哨兵。共有 3 种放置方案能够覆盖全部 6 个格子。

### 示例 2

**输入：**
```
3 3
```

**输出：**
```
3
4
```

**解释：**
在 3×3 的网格中，最少需要 3 个哨兵。

---

## 📌 数据范围

- 1 ≤ m, n ≤ 10
- 时间限制：10 秒

---

## 💡 算法提示

本题可以使用以下方法：

1. **回溯法 + 剪枝**：枚举每个格子是否放置哨兵，使用剪枝优化
   - 最优性剪枝：当前哨兵数 ≥ 已知最优解时剪枝
   - 可行性剪枝：如果某格子将永远无法被覆盖，强制在当前位置放置哨兵

2. **状态压缩动态规划**：将每行的状态压缩成二进制

3. **贪心 + 搜索**：优先尝试不放置，可以更快找到较优解

---

## 🎯 关键观察

1. **覆盖范围**：每个哨兵覆盖自己和上下左右共5个格子
2. **最后机会**：当处理到 (r, c) 时，如果 (r-1, c) 还未被覆盖，必须在此放置哨兵
3. **回溯机制**：放置哨兵后递归，返回时需要撤销放置

---

**目标：** 使用回溯法配合有效剪枝，在时间限制内求解最优解。
