## 问题分析

### 题目要求

- 在 m × n 的网格中布置哨兵
- 每个哨兵可以监视自己和上下左右共5个格子
- 求最少需要多少个哨兵覆盖全部格子
- 求达到最少数量的方案数

### 问题本质

这是一个**最小支配集问题（Minimum Dominating Set）**在网格图上的特例，属于 NP-Hard 问题。

### 关键约束

1. **完全覆盖**：每个格子至少被一个哨兵监视
2. **最小化**：使用的哨兵数量最少
3. **计数**：统计所有达到最优的方案

---

## 思路解析

### 错误直觉 ❌

- **贪心选择覆盖最多的位置**：不能保证全局最优
- **每隔固定距离放置**：可能放多了或放少了
- **随机搜索**：效率太低

### 正确思路 ✅

使用**回溯法 + 强力剪枝**：

1. **按顺序遍历**：从左到右、从上到下遍历每个格子
2. **二分支决策**：每个格子决定"放"或"不放"哨兵
3. **剪枝优化**：
   - 最优性剪枝：当前数量 ≥ 已知最优时停止
   - 可行性剪枝：某格子将无法被覆盖时强制放置

## 算法详解

### 1. 核心思想：可行性剪枝

当遍历到格子 (r, c) 时：

```
如果 (r-1, c) 还没被覆盖：
    这是覆盖 (r-1, c) 的最后机会！
    必须在 (r, c) 放置哨兵
```

**为什么是最后机会？**
- 能覆盖 (r-1, c) 的位置只有：(r-1, c)、(r-2, c)、(r-1, c-1)、(r-1, c+1)、(r, c)
- 前四个位置在遍历顺序上都在 (r, c) 之前，已经处理过了
- 如果 (r-1, c) 还没被覆盖，只有 (r, c) 能拯救它

### 2. 覆盖计数机制

使用一个二维数组记录每个格子被覆盖的次数：

```c
int grid[M][N];  // grid[i][j] = (i,j) 被覆盖的次数

void update_coverage(int r, int c, int val) {
    grid[r][c] += val;           // 自己
    if (r > 0) grid[r-1][c] += val;     // 上
    if (r < M-1) grid[r+1][c] += val;   // 下
    if (c > 0) grid[r][c-1] += val;     // 左
    if (c < N-1) grid[r][c+1] += val;   // 右
}
```

- 放置哨兵时调用 `update_coverage(r, c, +1)`
- 回溯时调用 `update_coverage(r, c, -1)`

### 3. 回溯框架

```c
void dfs(int k, int current_guards) {
    // 剪枝1：超过已知最优解
    if (current_guards > min_guards) return;
    
    // 终止条件：遍历完所有格子
    if (k == M * N) {
        // 检查最后一行是否全覆盖
        if (all_covered()) {
            update_answer(current_guards);
        }
        return;
    }
    
    int r = k / N, c = k % N;
    
    // 剪枝2：可行性剪枝
    if (must_place(r, c)) {
        place_guard(r, c);
        dfs(k + 1, current_guards + 1);
        remove_guard(r, c);  // 回溯
    } else {
        // 分支1：不放
        dfs(k + 1, current_guards);
        
        // 分支2：放（如果有意义）
        if (current_guards + 1 <= min_guards) {
            place_guard(r, c);
            dfs(k + 1, current_guards + 1);
            remove_guard(r, c);
        }
    }
}
```

### 4. 优化：先尝试不放

```c
// 优先尝试不放，有助于快速找到较小的解
dfs(k + 1, current_guards);  // 先不放

// 再尝试放
place_guard(r, c);
dfs(k + 1, current_guards + 1);
remove_guard(r, c);
```

这种顺序可以更快找到较优解，从而更早触发剪枝。

## 代码实现

### C 语言核心代码

```c
int M, N;
int grid[105][105];  // 覆盖计数
int min_guards;
int solution_count;

void update_coverage(int r, int c, int val) {
    grid[r][c] += val;
    if (r > 0) grid[r-1][c] += val;
    if (r < M-1) grid[r+1][c] += val;
    if (c > 0) grid[r][c-1] += val;
    if (c < N-1) grid[r][c+1] += val;
}

void dfs(int k, int guards) {
    if (guards > min_guards) return;  // 剪枝1
    
    if (k == M * N) {
        // 检查最后一行
        for (int j = 0; j < N; j++) {
            if (grid[M-1][j] == 0) return;
        }
        // 更新答案
        if (guards < min_guards) {
            min_guards = guards;
            solution_count = 1;
        } else if (guards == min_guards) {
            solution_count++;
        }
        return;
    }
    
    int r = k / N, c = k % N;
    
    // 可行性剪枝
    int must_place = 0;
    if (r > 0 && grid[r-1][c] == 0) must_place = 1;
    else if (r == M-1 && c > 0 && grid[r][c-1] == 0) must_place = 1;
    else if (r == M-1 && c == N-1 && grid[r][c] == 0) must_place = 1;
    
    if (must_place) {
        update_coverage(r, c, 1);
        dfs(k + 1, guards + 1);
        update_coverage(r, c, -1);
    } else {
        dfs(k + 1, guards);  // 不放
        
        if (guards + 1 <= min_guards) {
            update_coverage(r, c, 1);
            dfs(k + 1, guards + 1);
            update_coverage(r, c, -1);
        }
    }
}
```

## 复杂度分析

### 时间复杂度

- **最坏情况**：O(2^(m×n))，每个格子两种选择
- **剪枝后**：大大减少，通常能在几秒内解决 m, n ≤ 10 的情况

### 空间复杂度

- **覆盖数组**：O(m × n)
- **递归栈**：O(m × n)
- **总体**：O(m × n)

## 常见错误

1. **忘记回溯**
   ```c
   // ❌ 只放不收
   update_coverage(r, c, 1);
   dfs(k + 1, guards + 1);
   // 忘了 update_coverage(r, c, -1);
   
   // ✅ 必须回溯
   update_coverage(r, c, 1);
   dfs(k + 1, guards + 1);
   update_coverage(r, c, -1);  // 回溯！
   ```

2. **覆盖计数与放置哨兵混淆**
   ```c
   // ❌ 错误：直接设为1
   grid[r][c] = 1;
   
   // ✅ 正确：使用计数
   grid[r][c] += 1;  // 可能被多个哨兵覆盖
   ```

3. **边界检查遗漏**
   ```c
   // ❌ 越界访问
   grid[r-1][c] += val;  // r=0 时越界
   
   // ✅ 正确：先检查边界
   if (r > 0) grid[r-1][c] += val;
   ```

4. **剪枝条件错误**
   ```c
   // ❌ 错误：不应该用 >=
   if (guards >= min_guards) return;
   
   // ✅ 正确：用 > 允许相等（方便计数）
   if (guards > min_guards) return;
   ```

## 扩展思考

1. **状态压缩 DP**
   - 可以用位运算压缩每行的状态
   - 时间复杂度 O(m × 3^n)

2. **对称性优化**
   - 利用旋转/镜像对称减少搜索空间

3. **IDA* 搜索**
   - 使用迭代加深 + 估价函数

4. **更大规模问题**
   - 考虑近似算法或启发式搜索

5. **变形问题**
   - 哨兵只能放在特定位置
   - 不同类型的哨兵有不同覆盖范围

---

**总结：** 哨兵问题是经典的回溯法应用，关键在于设计有效的剪枝策略。可行性剪枝（强制放置）是本题的核心技巧。👍
