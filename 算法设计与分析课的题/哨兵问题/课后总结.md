## 思路关键点
问题的关键就是剪枝
首先 计数器大于当前最小值了，得剪枝
其次 如果这个位置选择不放哨兵，但是这个位置的上方没有被覆盖，那么剪枝

然后要注意回溯算法得撤销操作
最后遍历结束后，return全局变量min即可

1. **回溯法框架**：
   ```
   dfs(当前位置, 当前哨兵数):
       if 遍历完毕:
           检查是否全覆盖
           return
       
       if 强制放置条件:
           放置哨兵
           dfs(下一个位置, 哨兵数+1)
           撤销哨兵（回溯）
       else:
           dfs(下一个位置, 哨兵数)  // 不放
           放置哨兵
           dfs(下一个位置, 哨兵数+1)
           撤销哨兵
   ```

2. **可行性剪枝（最后机会）**：
   - 如果 (r-1, c) 未被覆盖
   - 且已经走到 (r, c)
   - 必须在 (r, c) 放置哨兵
   - 因为之后再也没机会覆盖 (r-1, c)

3. **覆盖计数**：
   - 使用 covered[i][j] 记录被覆盖次数
   - 放置时 +1，回溯时 -1
   - 检查全覆盖：所有格子 > 0

4. **优化技巧**：
   - 先尝试不放，更快找到较小解
   - 剪枝：当前数量 > 已知最优时停止
