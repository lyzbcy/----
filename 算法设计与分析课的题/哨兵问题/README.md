# 哨兵布置问题 (Sentinel Problem / Grid Dominating Set)

## 1. 问题描述
在一个 $m \times n$ 的陈列室中，需要布置哨兵。
- 每个哨兵可以监视自己所在的方格以及上下左右四个相邻的方格。
- 目标：求监视整个陈列室所需的**最小哨兵数量**，以及该数量下的**最优解方案数**。

## 2. 算法思路
本题采用 **回溯法 (Backtracking)** 结合 **剪枝优化 (Pruning)** 来求解。

### 核心逻辑
我们按顺序（从左到右，从上到下）遍历每一个格子，决定是否在该格子放置哨兵。

### 剪枝策略
为了在 10 秒内通过测试，必须进行强力剪枝：

1.  **最优性剪枝 (Optimality Pruning)**:
    - 如果当前放置的哨兵数量已经超过了（或等于，视具体逻辑而定）目前找到的最小哨兵数，则停止继续搜索该分支。

2.  **可行性剪枝 (Feasibility Pruning) - 关键**:
    - 当我们处理到第 `(r, c)` 个格子时，如果其上方第 `(r-1, c)` 个格子还没有被监视到，那么我们**必须**在当前格子 `(r, c)` 放置哨兵。
    - 原因：`(r, c)` 是最后一个能覆盖 `(r-1, c)` 的位置。一旦离开 `(r, c)` 继续往后搜索，`(r-1, c)` 将永远无法被覆盖（因为后续的格子都在 `(r, c)` 之后，无法覆盖到 `r-1` 行）。

## 3. 文件说明

### `solution.py` (Python 题解)
这是核心算法的 Python 实现。
- **运行方式**:
  ```bash
  python solution.py 2 3
  ```
  或者直接运行，然后输入一行两个整数：
  ```bash
  python solution.py
  2 3
  ```
- **输出**:
  第一行：最小哨兵数
  第二行：最优解的个数

### `index.html` (交互式可视化)
这是一个网页程序，用于直观地演示算法的运行过程。
- **使用方法**: 双击打开 `index.html` 文件（使用浏览器）。
- **功能**:
  - 设置行数 `m` 和列数 `n`。
  - 调整演示速度。
  - 点击“开始运行”可以看到算法是如何一步步尝试放置哨兵、回溯以及剪枝的。
  - 红色文字表示触发了剪枝（例如：因为上方格子未被覆盖而强制放置，或因为哨兵数过多而停止）。
  - 绿色文字表示找到了一个解。

## 4. 示例
输入:
```
2 3
```
输出:
```
2
3
```
解释：在 2x3 的网格中，最少需要 2 个哨兵。一共有 3 种放置 2 个哨兵且覆盖全图的方案。
