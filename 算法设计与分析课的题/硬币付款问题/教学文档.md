## 问题分析

### 题目要求

- 给定一系列不同面值的硬币及其对应的重量
- 目标：支付特定金额
- 要求：找到支付该金额时的**最轻总重量**

### 与经典背包的区别

| 问题类型 | 目标 | 约束 | 物品使用次数 |
|----------|------|------|--------------|
| 0-1背包 | 最大价值 | 容量限制 | 每种最多1次 |
| 完全背包 | 最大价值 | 容量限制 | 每种无限次 |
| **本题** | **最小重量** | 恰好凑够金额 | 每种无限次 |

### 关键约束

1. **恰好支付**：必须恰好凑够目标金额，不能多也不能少
2. **最小化重量**：在能凑够的前提下，使总重量最小
3. **无限使用**：每种硬币可以使用无限次

## 思路解析

### 错误直觉 ❌

- **贪心选择最轻的硬币**：可能无法凑够金额
- **贪心选择面值最大的硬币**：可能不是最轻方案
- **只考虑硬币数量**：题目要求的是重量，不是数量

### 正确思路 ✅

本题是**完全背包问题的变形**，使用动态规划：

1. **状态定义**：`dp[i]` 表示凑够金额 i 所需的最小重量

2. **状态转移**：
   - 对于每个金额 i，尝试使用每种硬币
   - `dp[i] = min(dp[i], dp[i - coin[j]] + weight[j])`
   - 前提是 `i >= coin[j]` 且 `dp[i - coin[j]]` 有效

3. **边界条件**：
   - `dp[0] = 0`（凑够0元需要0重量）
   - 其他初始化为无穷大（表示无法凑够）

4. **最终答案**：`dp[target]`

## 算法详解

### 1. 状态转移方程

```
dp[i] = min(dp[i], dp[i - coin[j]] + weight[j])

其中：
- i 是当前要凑的金额
- j 遍历所有硬币种类
- coin[j] 是第j种硬币的面值
- weight[j] 是第j种硬币的重量
```

### 2. 填表顺序

因为每种硬币可以无限使用（完全背包），所以**正序遍历**金额：

```c
for (int i = 1; i <= target; i++) {      // 遍历金额（正序！）
    for (int j = 0; j < n; j++) {         // 遍历每种硬币
        if (coin[j] <= i && dp[i - coin[j]] != INF) {
            dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);
        }
    }
}
```

### 3. 为什么正序遍历？

- **0-1 背包**：逆序遍历，保证每种物品只用一次
- **完全背包**：正序遍历，允许同一物品多次使用

正序遍历时，`dp[i - coin[j]]` 可能已经包含了使用 coin[j] 的结果，这正是我们期望的（可以重复使用）。

### 4. 图解示例

假设 coins = [2, 5], weights = [3, 4], target = 6

```
初始：dp = [0, INF, INF, INF, INF, INF, INF]

i=1: 没有面值为1的硬币，dp[1]=INF
i=2: 可用coin=2，dp[2] = dp[0] + 3 = 3
i=3: 没有合适的硬币，dp[3]=INF
i=4: 可用coin=2，dp[4] = dp[2] + 3 = 6
i=5: 可用coin=5，dp[5] = dp[0] + 4 = 4
i=6: 可用coin=2，dp[6] = dp[4] + 3 = 9
     可用coin=5，更新失败（dp[1]=INF）

最终：dp[6] = 9（使用3个面值2的硬币）
```

## 代码实现

### C 语言核心代码

```c
#include <stdio.h>
#include <string.h>

#define MAX_TARGET 1005
#define INF 0x3f3f3f3f

int coin[15], weight[15];  // 硬币面值和重量
int dp[MAX_TARGET];        // dp[i] = 凑够金额i的最小重量

int min(int a, int b) {
    return a < b ? a : b;
}

int main() {
    int n;  // 硬币种类数
    
    // 读取输入
    // 第一行：硬币面值
    // 第二行：硬币重量
    // 第三行：目标金额
    
    // 读取硬币面值
    char line[1000];
    fgets(line, sizeof(line), stdin);
    n = 0;
    char *p = strtok(line, " \n");
    while (p) {
        coin[n++] = atoi(p);
        p = strtok(NULL, " \n");
    }
    
    // 读取硬币重量
    fgets(line, sizeof(line), stdin);
    int idx = 0;
    p = strtok(line, " \n");
    while (p) {
        weight[idx++] = atoi(p);
        p = strtok(NULL, " \n");
    }
    
    // 读取目标金额
    int target;
    scanf("%d", &target);
    
    // 初始化 dp 数组
    memset(dp, 0x3f, sizeof(dp));
    dp[0] = 0;
    
    // 动态规划（完全背包，正序遍历）
    for (int i = 1; i <= target; i++) {
        for (int j = 0; j < n; j++) {
            if (coin[j] <= i && dp[i - coin[j]] != INF) {
                dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);
            }
        }
    }
    
    printf("%d\n", dp[target]);
    
    return 0;
}
```

## 复杂度分析

### 时间复杂度

- **外层循环**：遍历目标金额 1 到 target，O(target)
- **内层循环**：遍历所有硬币种类，O(n)
- **总体**：O(n × target)

对于本题：n ≤ 10, target ≤ 1000，总运算约 10000 次，非常快。

### 空间复杂度

- **dp 数组**：O(target)
- **硬币信息**：O(n)
- **总体**：O(target + n)

## 常见错误

1. **遍历顺序错误**
   ```c
   // ✅ 完全背包：正序遍历
   for (int i = 1; i <= target; i++)
   
   // ❌ 如果逆序遍历，每种硬币只能用一次
   ```

2. **忘记检查 dp[i - coin[j]] 是否有效**
   ```c
   // ❌ 错误：没有检查是否能凑够
   dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);
   
   // ✅ 正确：需要验证前置状态有效
   if (dp[i - coin[j]] != INF) {
       dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);
   }
   ```

3. **初始化错误**
   ```c
   // ✅ 正确：dp[0]=0，其他为INF
   dp[0] = 0;
   for (int i = 1; i <= target; i++) dp[i] = INF;
   ```

4. **硬币和重量对应关系搞混**
   - 输入第一行是面值，第二行是重量
   - 第 i 个面值对应第 i 个重量

## 扩展思考

1. **最少硬币数问题**
   - 把"重量"改成"1"（每个硬币计数为1）
   - dp[i] 就变成凑够 i 元的最少硬币数

2. **方案数问题**
   - dp[i] 表示凑够 i 元的方案数
   - 状态转移：`dp[i] += dp[i - coin[j]]`

3. **恰好装满的背包**
   - 本题就是"恰好装满"的变形
   - 初始化技巧：dp[0]=0，其他=INF

4. **如果硬币数量有限制**
   - 变成"多重背包"问题
   - 需要额外考虑每种硬币的使用次数

5. **输出具体方案**
   - 额外记录 choice[i] = 凑够 i 元时最后使用的硬币
   - 从 target 反向追溯即可

---

**总结：** 本题是完全背包问题的变形，核心是理解"正序遍历允许重复使用"和"最小化目标的DP"。掌握本题后，可以举一反三解决各种货币兑换问题。👍
