## 批阅意见

### 常见错误提醒

在批阅学生代码时，请重点关注以下常见问题：

#### 1. 遍历顺序错误 🔴

```c
// ❌ 错误：逆序遍历会导致每种硬币只能用一次
for (int i = target; i >= 1; i--)

// ✅ 正确：完全背包需要正序遍历
for (int i = 1; i <= target; i++)
```

#### 2. 忘记检查前置状态有效性

```c
// ❌ 错误：可能加上 INF 导致溢出
dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);

// ✅ 正确：需要检查 dp[i - coin[j]] 是否有效
if (dp[i - coin[j]] != INF) {
    dp[i] = min(dp[i], dp[i - coin[j]] + weight[j]);
}
```

#### 3. 初始化错误

```c
// ❌ 错误：全部初始化为0
memset(dp, 0, sizeof(dp));

// ✅ 正确：dp[0]=0，其他为INF
dp[0] = 0;
for (int i = 1; i <= target; i++) dp[i] = INF;
// 或使用 memset(dp, 0x3f, sizeof(dp)); dp[0] = 0;
```

#### 4. 输入解析错误

```c
// 输入格式注意：
// 第一行：硬币面值（空格分隔）
// 第二行：硬币重量（空格分隔）
// 第三行：目标金额
```

#### 5. 把"最小重量"误解为"最少硬币数"

```c
// 题目要求的是最小重量，不是最少硬币数！
// 不能简单地把所有硬币重量设为1
```

## 📝 参考答案要点

1. **状态定义**：`dp[i]` 表示凑够金额 i 所需的最小重量
2. **状态转移**：`dp[i] = min(dp[i], dp[i-coin[j]] + weight[j])`
3. **遍历顺序**：正序遍历金额（完全背包特征）
4. **初始化**：dp[0]=0，其他为INF
5. **时间复杂度**：O(n × target)
