# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序提供三个内置选项：

- 选项 1：题目样例
- 选项 2：简单示例 coins=[1,2,5], weights=[2,3,6], target=11
- 选项 3：自定义输入

---

| 按键 | 功能 |

---

## 📊 动画元素说明

- **蓝色柱子**：已计算的 dp 值
- **红色柱子**：当前正在更新的位置
- **灰色柱子**：无法凑够（dp 值为 INF）
- **∞ 标记**：表示该金额无法被凑够

---

## 🔁 动画流程

1. **初始化**：dp[0]=0，其他为 INF
2. **遍历金额**：从 1 到 target
3. **尝试每种硬币**：如果可用，更新 dp 值
4. **结束**：显示凑够目标金额的最小重量

---

## 💡 学习建议

1. **第一次观看**：选择简单示例，观察基本的填表流程
   - 注意正序遍历金额
   - 观察每种硬币如何影响 dp 值

2. **第二次**：尝试题目样例
   - 观察更多硬币种类的情况
   - 理解为什么需要取最小值

3. **第三次**：自定义输入
   - 预测下一步的更新
   - 验证你的分析

---

## 🎯 关键观察点

1. **正序遍历**：允许同一硬币重复使用

2. **状态转移**：
   - `dp[i] = min(dp[i], dp[i-coin] + weight)`
   - 前提是 `dp[i-coin]` 不是 INF

3. **最小化目标**：
   - 取所有可能方案中的最小重量
   - 与"最大价值"的背包正好相反

---

## ❓ 常见问题

- **柱子太多显示不完？**  
  当目标金额较大时，只显示前20个格子。

- **中文显示异常？**  
  修改脚本中的 `plt.rcParams['font.sans-serif']`。

- **∞ 是什么意思？**  
  表示该金额无法被凑够（没有合适的硬币组合）。
