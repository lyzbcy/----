## 思路关键点

1. **完全背包变形**：
   - 每种硬币可以无限使用
   - 目标是最小化重量（不是最大化价值）

2. **正序遍历**：
   ```
   for i = 1 to target:
       for each coin:
           dp[i] = min(dp[i], dp[i-coin] + weight)
   ```

3. **初始化技巧**：
   - dp[0] = 0（边界条件）
   - 其他 = INF（表示无法凑够）

4. **有效性检查**：
   - 更新前需要检查 dp[i-coin] 是否有效
