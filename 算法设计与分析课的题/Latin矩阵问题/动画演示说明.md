# 动画演示使用说明

## 🎬 如何运行动画

1. **安装依赖**

```bash
pip install matplotlib numpy
```

2. **运行程序**

```bash
python 动画演示.py
```

3. **选择示例**

程序提供两个内置选项：

- 选项 1：n = 3（3阶拉丁方，步骤较少）
- 选项 2：n = 4（4阶拉丁方，题目要求）

---

## 🎮 手动控制方式

| 按键 | 功能 |
|------|------|
| 空格 / → / Enter | 下一步 |
| ← | 上一步 |
| Home | 跳转到第一步 |
| End | 跳转到最后一步 |
| Q / Esc | 退出程序 |

> ⚠️ 使用键盘前，请先点击动画窗口以确保焦点在窗口上。

---

## 📊 动画元素说明

- **浅蓝色格子**：第一行（固定为 1,2,3,...,n）
- **绿色格子**：当前正在放置数字的位置
- **红色格子**：正在回溯（移除数字）的位置
- **黄色格子**：找到解时的当前位置
- **白色格子**：未填充的格子

---

## 🔁 动画流程

1. **初始化**：第一行固定为 1,2,3,...,n
2. **逐格填充**：从第2行第1列开始
3. **尝试数字**：对每个位置尝试 1 到 n
4. **约束检查**：检查行约束和列约束
5. **递归或回溯**：满足则继续，否则回溯
6. **找到解**：填满时记录一个解

---

## 💡 学习建议

1. **第一次观看**：选择 n=3，观察完整的搜索过程
   - 注意放置和回溯的交替
   - 观察约束如何限制选择

2. **第二次**：选择 n=4
   - 观察更大规模的搜索树
   - 理解为什么有些分支会回溯

3. **思考问题**：
   - 为什么需要回溯？
   - 如何加速搜索？

---

## 🎯 关键观察点

1. **约束传播**：
   - 放置一个数后，该行该列都不能再用这个数
   - 回溯时需要恢复约束

2. **搜索顺序**：
   - 按行按列顺序填充
   - 也可以尝试其他顺序

3. **解的数量**：
   - n=4 时有 576 个拉丁方
   - 第一行固定后有 24 个

---

## ❓ 常见问题

- **步骤太多看不完？**  
  可以使用 End 键跳到最后，查看最终找到了多少个解。

- **中文显示异常？**  
  修改脚本中的 `plt.rcParams['font.sans-serif']`。

- **程序卡住了？**  
  n=4 时步骤较多，请耐心等待加载完成。
