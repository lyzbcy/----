## 问题分析

### 什么是拉丁方

**拉丁方（Latin Square）** 是一个 n×n 的方阵，满足：
- 每行包含 1 到 n 的每个数字恰好一次
- 每列包含 1 到 n 的每个数字恰好一次

### 题目要求

- 生成所有**第一行为 1, 2, 3, ..., n** 的 n 阶拉丁方
- 对于每个解，输出第 2 行到第 n 行的数字序列
- n = 4 或 5

### 关键约束

1. **行约束**：每行的数字不能重复
2. **列约束**：每列的数字不能重复
3. **第一行固定**：第一行固定为 1, 2, 3, ..., n

## 思路解析

### 与其他问题的联系

| 问题 | 约束类型 | 解法 |
|------|----------|------|
| N 皇后 | 行、列、对角线 | 回溯法 |
| 数独 | 行、列、3×3 宫格 | 回溯法 |
| **拉丁方** | 行、列 | 回溯法 |

### 正确思路 ✅

使用 **回溯法（Backtracking）** 逐格填充：

1. **按顺序填充**：从第 2 行第 1 列开始，逐行逐列填充
2. **尝试每个数字**：对于每个位置，尝试 1 到 n 的每个数字
3. **检查约束**：该数字是否在当前行、当前列出现过
4. **递归或回溯**：满足约束则继续，否则回溯尝试下一个数字
5. **记录解**：填满所有格子时记录一个解

## 算法详解

### 1. 回溯法框架

```
solve(row, col):
    if row == n:
        记录当前解
        return
    
    next_row, next_col = 计算下一个位置
    
    for num = 1 to n:
        if num 不在 row 行 and num 不在 col 列:
            matrix[row][col] = num
            solve(next_row, next_col)
            matrix[row][col] = 0  // 回溯
```

### 2. 约束检查

使用两个布尔数组快速判断：

```c
bool rowUsed[n][n+1];  // rowUsed[r][x] = true 表示第r行已使用数字x
bool colUsed[n][n+1];  // colUsed[c][x] = true 表示第c列已使用数字x
```

检查是否可以放置：
```c
bool canPlace(int row, int col, int num) {
    return !rowUsed[row][num] && !colUsed[col][num];
}
```

### 3. 放置与回溯

```c
void place(int row, int col, int num) {
    matrix[row][col] = num;
    rowUsed[row][num] = true;
    colUsed[col][num] = true;
}

void remove(int row, int col, int num) {
    matrix[row][col] = 0;
    rowUsed[row][num] = false;
    colUsed[col][num] = false;
}
```

### 4. 递归搜索

```c
void solve(int row, int col) {
    // 递归终止：填完所有行
    if (row == n) {
        记录并输出当前解;
        return;
    }
    
    // 计算下一个位置
    int nextRow = (col == n - 1) ? row + 1 : row;
    int nextCol = (col == n - 1) ? 0 : col + 1;
    
    // 尝试每个数字
    for (int num = 1; num <= n; num++) {
        if (canPlace(row, col, num)) {
            place(row, col, num);
            solve(nextRow, nextCol);
            remove(row, col, num);  // 回溯
        }
    }
}
```

## 代码实现

### C 语言核心代码

```c
#include <stdio.h>
#include <stdbool.h>
#include <string.h>

int n;
int matrix[6][6];
bool rowUsed[6][7];  // rowUsed[r][num] = 第r行是否使用了num
bool colUsed[6][7];  // colUsed[c][num] = 第c列是否使用了num

void solve(int row, int col) {
    // 递归终止：填完所有行
    if (row == n) {
        // 输出第2行到第n行
        for (int r = 1; r < n; r++) {
            for (int c = 0; c < n; c++) {
                printf("%d", matrix[r][c]);
                if (r != n - 1 || c != n - 1) printf(" ");
            }
        }
        printf("\n");
        return;
    }
    
    // 计算下一个位置
    int nextRow = (col == n - 1) ? row + 1 : row;
    int nextCol = (col == n - 1) ? 0 : col + 1;
    
    // 尝试每个数字
    for (int num = 1; num <= n; num++) {
        if (!rowUsed[row][num] && !colUsed[col][num]) {
            // 放置
            matrix[row][col] = num;
            rowUsed[row][num] = true;
            colUsed[col][num] = true;
            
            // 递归
            solve(nextRow, nextCol);
            
            // 回溯
            matrix[row][col] = 0;
            rowUsed[row][num] = false;
            colUsed[col][num] = false;
        }
    }
}

int main() {
    scanf("%d", &n);
    
    // 初始化
    memset(rowUsed, false, sizeof(rowUsed));
    memset(colUsed, false, sizeof(colUsed));
    
    // 第一行固定为 1, 2, 3, ..., n
    for (int i = 0; i < n; i++) {
        matrix[0][i] = i + 1;
        rowUsed[0][i + 1] = true;
        colUsed[i][i + 1] = true;
    }
    
    // 从第2行第1列开始搜索
    solve(1, 0);
    
    return 0;
}
```

## 复杂度分析

### 时间复杂度

- **最坏情况**：每个位置尝试 n 个数字
- **位置总数**：(n-1) × n（第一行固定）
- **上界**：O(n^(n² - n)) 非常大，但剪枝后实际很快

对于 n=4，有效的 4 阶拉丁方数量是 576，第一行固定后是 **24** 个。
对于 n=5，第一行固定后有 **56** 个。

### 空间复杂度

- **矩阵**：O(n²)
- **约束数组**：O(n²)
- **递归栈**：O(n²)
- **总体**：O(n²)

## 常见错误

1. **忘记初始化第一行的约束**
   ```c
   // ✅ 第一行固定后，要标记已使用
   for (int i = 0; i < n; i++) {
       colUsed[i][i + 1] = true;
       rowUsed[0][i + 1] = true;
   }
   ```

2. **回溯时忘记恢复状态**
   ```c
   // ❌ 忘记回溯
   solve(nextRow, nextCol);
   
   // ✅ 必须恢复
   solve(nextRow, nextCol);
   matrix[row][col] = 0;
   rowUsed[row][num] = false;
   colUsed[col][num] = false;
   ```

3. **输出格式错误**
   ```c
   // 题目要求：输出第2-n行的数字，用空格分隔
   // 注意处理最后一个数字后不要有空格
   ```

4. **递归终止条件错误**
   ```c
   // ✅ 正确：行号等于n时结束
   if (row == n) { ... }
   
   // ❌ 错误：可能漏掉最后一个位置
   if (row == n - 1 && col == n - 1) { ... }
   ```

## 扩展思考

1. **统计解的个数**
   - 添加计数器，不输出具体的解

2. **优化搜索顺序**
   - 优先填约束最多的位置（MRV 启发式）

3. **对称性剪枝**
   - 利用拉丁方的对称性减少搜索空间

4. **增量验证**
   - 使用约束传播，提前发现无解分支

5. **扩展到更大的 n**
   - 需要更强的剪枝策略
   - 可以使用 Dancing Links 等高级技术
