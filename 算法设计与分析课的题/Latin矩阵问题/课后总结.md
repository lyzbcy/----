## 思路关键点

1. **回溯法框架**：
   ```
   solve(当前位置):
       if 填完了:
           记录解
           return
       
       for 每个选择:
           if 满足约束:
               做选择
               solve(下一个位置)
               撤销选择（回溯）
   ```

2. **约束检查**：
   - 行约束：该数字不在当前行
   - 列约束：该数字不在当前列

3. **状态标记**：
   - 放置时标记 rowUsed 和 colUsed
   - 回溯时恢复标记

4. **第一行固定**：
   - 减少搜索空间
   - 需要预先标记约束
