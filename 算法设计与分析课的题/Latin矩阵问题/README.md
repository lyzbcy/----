## 📖 学习路径

1. **阅读题目要求**  
   打开 `题目描述.md`，理解题目背景、输入输出与约束。

2. **观看动画演示（强烈推荐）🎬**  
   运行 `python 动画演示.py`，直观观察回溯法的搜索过程。  
   详细操作说明见 `动画演示说明.md`。

3. **深入理解思路**  
   打开 `教学文档.md`，逐步掌握：
   - 问题分析
   - 回溯法核心思想
   - 约束满足问题
   - 剪枝优化技巧
   - 常见陷阱与边界处理

4. **查看代码实现**  
   根据需要查阅 `答案.c` 或 `答案.cpp`。

5. **复盘总结**  
   在完成题目后，填写 `课后总结.md` 模板，巩固所学。

## 🎯 核心知识点

- 回溯法（Backtracking）的应用
- 约束满足问题（CSP）
- 拉丁方的数学性质
- 递归与回溯的配合
- 剪枝优化策略
- 解的枚举与输出

## 🎬 快速开始动画演示

```bash
# 安装依赖
pip install matplotlib numpy

# 运行动画
python 动画演示.py
```

动画支持手动逐步播放，方便你按照自己的节奏理解回溯法的每一步搜索与回退过程。
