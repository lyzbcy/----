# 补充学习：洛谷 P1257 平面上的最接近点对

> 🔗 **题目链接**：[洛谷 P1257](https://www.luogu.com.cn/problem/P1257)

---

## 📝 题目描述

给定平面上 n 个点，找出其中的一对点的距离，使得在这 n 个点的所有点对中，该距离为所有点对中最小的。

---

## 📥 输入格式

- 第一行一个整数 n，表示点的个数
- 接下来 n 行，每行两个整数 x, y，表示一个点的**横坐标**和**纵坐标**

---

## 📤 输出格式

- 仅一行，一个实数，表示最短距离，**四舍五入保留 4 位小数**

---

## 📊 数据范围

- 对于 100% 的数据：$1 \leq n \leq 10^4$
- $0 \leq x, y \leq 10^9$

---

## ⚠️ 与课程版本的差异

| 对比项 | 课程版本 | 洛谷 P1257 |
|--------|----------|------------|
| 数据范围 n | $1 \leq n \leq 10^5$ | $1 \leq n \leq 10^4$ |
| 小数位数 | 保留 **2** 位小数 | 保留 **4** 位小数 |
| 坐标范围 | $0 \leq x, y \leq 10^9$ | $0 \leq x, y \leq 10^9$ |

> [!IMPORTANT]

## 💻 适配答案（C++ 版本）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
const double INF = 1e18;

struct Point {
    double x, y;
} p[MAXN], tmp[MAXN];

int n;

bool cmpX(const Point& a, const Point& b) {
    return a.x < b.x;
}

bool cmpY(const Point& a, const Point& b) {
    return a.y < b.y;
}

double dist(const Point& a, const Point& b) {
    return sqrt((a.x - b.x) * (a.x - b.x) + (a.y - b.y) * (a.y - b.y));
}

double solve(int l, int r) {
    if (l >= r) return INF;
    if (r - l == 1) return dist(p[l], p[r]);
    
    int mid = (l + r) >> 1;
    double midX = p[mid].x;
    
    double d = min(solve(l, mid), solve(mid + 1, r));
    
    // 收集中间区域的点
    int cnt = 0;
    for (int i = l; i <= r; i++) {
        if (fabs(p[i].x - midX) < d) {
            tmp[cnt++] = p[i];
        }
    }
    
    // 按 y 坐标排序
    sort(tmp, tmp + cnt, cmpY);
    
    // 检查中间区域的点对
    for (int i = 0; i < cnt; i++) {
        for (int j = i + 1; j < cnt && tmp[j].y - tmp[i].y < d; j++) {
            d = min(d, dist(tmp[i], tmp[j]));
        }
    }
    
    return d;
}

int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%lf%lf", &p[i].x, &p[i].y);
    }
    
    sort(p, p + n, cmpX);
    
    printf("%.4lf\n", solve(0, n - 1));
    
    return 0;
}
```

---

## 🎯 解题要点

### 1. 分治策略
1. 将点按 x 坐标排序
2. 找到中间位置，递归求解左右两部分的最小距离 d
3. 处理跨越中线的点对（关键步骤）

### 2. 时间复杂度分析
- 排序：$O(n \log n)$
- 分治递归：$T(n) = 2T(n/2) + O(n \log n)$
- 总复杂度：$O(n \log^2 n)$

### 3. 常见优化
- **归并排序代替 sort**：将复杂度优化到 $O(n \log n)$
- **剪枝**：y 坐标差超过 d 时直接跳出
