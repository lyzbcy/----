# 零钱系统问题

题目来源：算法设计与分析课程作业

---

## 📝 题目描述

假设零钱系统的币值是 **{1, p, p², ..., pⁿ}**，其中 **p > 1**，且每个钱币的重量都等于 **1**。

设计一个**最坏情况下时间复杂度最低**的算法，使得对任何钱数 **y**，该算法得到的**零钱个数最少**。

### 要求

1. 说明该算法的**主要设计思想**
2. **证明**它的**准确性**
3. 给出**最坏情况下的时间复杂度**

---

## 📥 输入形式

- p：币值的基数（p > 1）
- n：最大幂次
- y：目标金额

---

## 📤 输出形式

- 输出最少需要的硬币个数
- （可选）输出每种面值硬币的使用数量

---

## 🔢 示例

### 样例输入

```
p = 3, n = 3, y = 23
```

币值系统为：{1, 3, 9, 27}

### 样例输出

```
最少硬币数：5
具体方案：2个9元 + 1个3元 + 2个1元 = 18 + 3 + 2 = 23
```

---

## 📌 样例说明

- 23 的 3 进制表示：23 = 2×9 + 1×3 + 2×1 = (212)₃
- 所需硬币数 = 2 + 1 + 2 = 5

---

## 💡 算法提示

当硬币面值为 **p 的幂次** {1, p, p², ..., pⁿ} 时，**贪心算法是最优的**！

这等价于将金额 y 转换为 **p 进制表示**，各位数字之和即为最少硬币数。

### 洛谷 P1010 幂次方（⭐⭐⭐ 高度相关）

**链接**：https://www.luogu.com.cn/problem/P1010

**题目描述**：
任何一个正整数都可以用 2 的幂次方表示。例如：
```
137 = 2⁷ + 2³ + 2⁰
```
同时约定用括号来表示次方，即 a^b 表示为 a(b)。

**与本题关系**：
- P1010 是将数表示为 2 的幂次之和（p=2 的特例）

- 核心思想都是**进制转换**

### 洛谷 B3635 硬币问题（⭐⭐ 相关但不同）

**链接**：https://www.luogu.com.cn/problem/B3635

**题目描述**：
面值为 1、5、11 元的硬币各无限枚，凑出 n 元需要的最少硬币数量。

**与本题区别**：
- B3635 的面值 {1, 5, 11} 不是几何级数，贪心不一定最优
- 本题面值 {1, p, p², ...} 是几何级数，贪心总是最优

---

## 🎯 关键洞察

> **当硬币面值构成几何级数（等比数列）且包含 1 时，贪心算法保证最优！**

这是因为每个较大面值都可以被恰好 p 个较小面值替代，形成完美的进制系统。
