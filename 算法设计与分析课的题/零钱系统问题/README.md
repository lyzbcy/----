# 零钱系统问题

## 📋 问题概述

设计最优算法求解零钱系统 {1, p, p², ..., pⁿ}（p>1）下，对任意金额 y 的最少硬币数。

## 🎯 核心结论

**贪心算法是最优解**：将 y 转换为 p 进制，各位数字之和即为答案。
