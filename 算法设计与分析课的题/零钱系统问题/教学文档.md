## 问题分析

### 题目理解

给定零钱系统的币值集合 **{1, p, p², ..., pⁿ}**，其中：
- p > 1（正整数）
- 每个硬币的重量都等于 1

**目标**：对于任意金额 y，找到使用**最少硬币数**的方案。

### 问题建模

设第 i 种面值为 $d_i = p^i$（$i = 0, 1, ..., n$）

设使用第 i 种面值的硬币数为 $c_i$

**优化目标**：

$$\min \sum_{i=0}^{n} c_i$$

**约束条件**：

$$\sum_{i=0}^{n} c_i \cdot p^i = y$$

$$c_i \geq 0, \quad c_i \in \mathbb{Z}$$

### 关键观察

币值系统 {1, p, p², ..., pⁿ} 构成**等比数列（几何级数）**：
- 公比为 p
- 包含面值 1（保证任何金额都可表示）
- 任意 p^(i+1) = p × p^i

这意味着：**y 的 p 进制表示就是最优解！**

## 算法设计思想

### 核心思想：贪心 = p 进制转换

**贪心策略**：从最大面值开始，每次尽可能多地使用当前最大面值的硬币。

**等价形式**：将金额 y 转换为 p 进制表示。

### 算法步骤

```
输入: y (目标金额), p (基数), n (最大幂次)
输出: 最少硬币数 total, 各面值使用数量 coins[]

1. total ← 0
2. remaining ← y
3. FOR i = n DOWN TO 0:
    (a) denomination ← p^i        // 当前面值
    (b) coins[i] ← remaining ÷ denomination  // 整除
    (c) remaining ← remaining mod denomination  // 取余
    (d) total ← total + coins[i]
4. RETURN total
```

### 示例演算

**输入**：p = 3, n = 3, y = 23

**币值系统**：{1, 3, 9, 27}

| 步骤 | 面值 | 使用数量 | 剩余金额 | 累计硬币 |
|------|------|----------|----------|----------|
| 初始 | - | - | 23 | 0 |
| i=3 | 27 | 23÷27=0 | 23 | 0 |
| i=2 | 9 | 23÷9=2 | 23%9=5 | 2 |
| i=1 | 3 | 5÷3=1 | 5%3=2 | 3 |
| i=0 | 1 | 2÷1=2 | 0 | 5 |

**结果**：
- 最少硬币数 = 5
- 方案：2×9 + 1×3 + 2×1 = 23
- 3进制表示：(212)₃

## 正确性证明

### 定理

对于币值系统 {1, p, p², ..., pⁿ}（p > 1），贪心算法得到的硬币数等于 y 在 p 进制下各位数字之和，且这是最少的。

### 证明

#### 第一部分：贪心结果等于 p 进制表示

设 y 的 p 进制表示为：

$$y = \sum_{i=0}^{n} a_i \cdot p^i, \quad 0 \leq a_i < p$$

这正是唯一的 p 进制表示。贪心算法从高位到低位计算商和余数，结果就是 p 进制的各位数字。

#### 第二部分：p 进制表示使用最少硬币

**使用反证法**。

假设存在另一种方案 $(b_0, b_1, ..., b_n)$，使得：
1. $\sum_{i=0}^{n} b_i \cdot p^i = y$
2. $\sum_{i=0}^{n} b_i < \sum_{i=0}^{n} a_i$

由于两种方案表示相同的数 y，我们考虑它们的差异。

**关键观察**：如果 $b_j > a_j$ 对某个 j 成立，则必须有其他位来"补偿"。

但在 p 进制中，每个 $a_i < p$，如果 $b_i \geq p$，我们可以进位：
- 用 p 个 $p^i$ 换成 1 个 $p^{i+1}$
- 硬币数减少 p - 1 ≥ 1（因为 p > 1）

这说明任何使用 $b_i \geq p$ 的方案都不是最优的。

因此，最优方案必须满足 $0 \leq b_i < p$，而这恰好是 **唯一的 p 进制表示**。

**结论**：贪心算法得到的就是最优解。 ∎

### 直观理解

| 面值替换 | 硬币数变化 |
|----------|------------|
| 1个 p² → p个 p¹ | +p-1 (变多) |
| 1个 p¹ → p个 p⁰ | +p-1 (变多) |

**向下替换总是增加硬币数**，所以贪心选择最大面值是正确的。

## 时间复杂度分析

### 算法分析

```
FOR i = n DOWN TO 0:     // 循环 n+1 次
    denomination ← p^i   // O(1) 或预处理
    coins[i] ← remaining ÷ denomination  // O(1)
    remaining ← remaining mod denomination  // O(1)
    total ← total + coins[i]  // O(1)
```

### 时间复杂度

- **循环次数**：n + 1
- **每次循环**：O(1)（假设整数运算为常数时间）
- **总时间复杂度**：**O(n)**

### 与 y 的关系

由于币值系统最大面值为 pⁿ，通常有：

$$p^n \geq y \quad \Rightarrow \quad n \geq \log_p(y)$$

因此也可以表示为：**O(log_p(y))**

### 空间复杂度

- coins 数组：O(n)
- 其他变量：O(1)
- **总空间复杂度**：**O(n)**

### 最坏情况

**最坏情况出现在**：y = pⁿ⁺¹ - 1（所有位都是 p-1）

例如 p=3, n=3：y = 81-1 = 80 = (2222)₃

但即使在最坏情况下，时间复杂度仍为 **O(n) = O(log_p(y))**，这是最优的！

## 代码实现

### 伪代码

```
ALGORITHM MinCoins(y, p, n)
INPUT:  y - 目标金额
        p - 币值基数
        n - 最大幂次
OUTPUT: 最少硬币数

1   total ← 0
2   remaining ← y
3   FOR i ← n DOWNTO 0
4       denomination ← p^i
5       count ← remaining DIV denomination
6       remaining ← remaining MOD denomination
7       total ← total + count
8   RETURN total
```

### C 语言实现

```c
int minCoins(int y, int p, int n) {
    int total = 0;
    int remaining = y;
    
    for (int i = n; i >= 0; i--) {
        int denomination = (int)pow(p, i);
        total += remaining / denomination;
        remaining %= denomination;
    }
    
    return total;
}
```

### 优化版本（避免重复计算幂）

```c
int minCoinsOptimized(int y, int p, int n) {
    // 预计算幂次
    int power[100];
    power[0] = 1;
    for (int i = 1; i <= n; i++) {
        power[i] = power[i-1] * p;
    }
    
    // 贪心求解
    int total = 0;
    int remaining = y;
    for (int i = n; i >= 0; i--) {
        total += remaining / power[i];
        remaining %= power[i];
    }
    
    return total;
}
```

## 算法对比

### 贪心 vs 动态规划

| 特征 | 贪心算法 | 动态规划 |
|------|----------|----------|
| **适用条件** | 币值为 p 的幂次 | 任意币值 |
| **时间复杂度** | O(log_p(y)) | O(n × y) |
| **空间复杂度** | O(log_p(y)) | O(y) |
| **是否最优** | ✅ 总是最优 | ✅ 总是最优 |
| **实现难度** | 简单 | 中等 |

### 何时贪心不适用？

当币值**不是**几何级数时，贪心可能失败：

**反例**：币值 {1, 3, 4}，y = 6
- 贪心：4 + 1 + 1 = 3 枚硬币
- 最优：3 + 3 = 2 枚硬币 ✅

## 扩展思考

### 1. 为什么几何级数保证贪心最优？

因为构成了一个**规范货币系统**（Canonical Coin System）：
- 每个面值都是前一个的倍数
- 不存在"跳过"某个面值更优的情况
- 等价于数的进制表示

### 2. 与实际货币的联系

实际货币系统（如人民币、美元）设计时考虑了贪心最优性：
- 人民币：1, 5, 10, 50, 100（近似几何级数）
- 但不是严格的几何级数，少数情况可能不是最优

### 3. 二进制的特殊情况

当 p = 2 时：
- 币值系统：{1, 2, 4, 8, 16, ...}
- y 的二进制表示中 1 的个数 = 最少硬币数
- 这就是洛谷 P1010 幂次方问题的核心

### 4. 输出具体方案

```c
void printSolution(int y, int p, int n) {
    printf("%d = ", y);
    int first = 1;
    for (int i = n; i >= 0; i--) {
        int power = (int)pow(p, i);
        int count = y / power;
        y %= power;
        if (count > 0) {
            if (!first) printf(" + ");
            printf("%d×%d^%d", count, p, i);
            first = 0;
        }
    }
    printf("\n");
}
```
